# Omni Sync

Omni Sync is a system that syncronises workspaces tasks calendars meetings applications and ideas between a web dashbaord and an Android companion app

![screenshot 1](pic/Screenshot%202026-08-01%20005441.png)

## Web dashboard Features
Executive dashboard Central view for system statuss updates and quick navigation
Applications applied Track submitted applications statuss and updates
calendar Monthly view to scehdule and visualise events
Daily planner Daily checklist and agenda planner
unified Meets Manage and join Google Meets and generl meetings
ideas Vault Store organize and categorize thoughts and concepts
Pending work Tracker View and track incomplete tasks and logs
settings Panel Manage configuration options and pair devices
firebase integration Synchronizes datbase values in real timee

## Android companion App features
device Pairing Match app with web dashbaord using generated sync codes
background Service Polls Firebase Realtime Datbase for pending notifcations
local Notifications Triggers system alerts for meetings tasks and applications with deep links
delivery Confirmations Sends acknoledgment receipt status back to datbase
